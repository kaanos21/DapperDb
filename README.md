# DapperDB

DapperDB is an application developed using ASP.NET Core 6.0. This project helps users find houses by allowing them to filter rental or sale properties and view detailed information about selected houses.

## Technologies and Tools Used 🤖

- **.NET Core 6.0**: Used as the core framework for the web application. ✅  
- **Dapper ORM**: Used for fast and efficient management of database queries. ✅  
- **Microsoft SQL Server**: Used for database management and storage. ✅  
- **CRUD Operations**: Basic CRUD operations (Create, Read, Update, Delete) are implemented in the application. ✅  

## Project Features

- **Related Tables**: The project supports querying and retrieving data from related tables. ✅  
- **Filtering**: Users can filter rental or sale properties. ✅  
- **Detail Viewing**: Users can view detailed features of selected houses. ✅  

## SOLID Principles

The project is developed following SOLID principles.

# DapperDB

DapperDB, ASP.NET Core 6.0 kullanılarak geliştirilmiş bir uygulamadır. Bu proje, kullanıcıların ev bulmalarını sağlamak amacıyla geliştirilmiştir. Kiralık veya satılık evleri filtreleyebilir ve seçilen evlerin detaylarını inceleyebilirsiniz.

- **Microsoft SQL Server**: Veritabanı yönetimi ve depolama için kullanıldı. ✅  
- **CRUD İşlemleri**: Uygulamada temel CRUD işlemleri gerçekleştirilmiştir (Create, Read, Update, Delete). ✅

- **Detay Görüntüleme**: Seçilen evlerin özelliklerini detaylı bir şekilde inceleyebilirsiniz. ✅
